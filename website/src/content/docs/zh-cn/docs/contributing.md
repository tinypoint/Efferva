Efferva 采用 Apache-2.0 许可证，以开放方式开发。

## 开始贡献

1. 阅读仓库工程约束。
2. 使用官方 Codex App Server 协议，不增加 Runtime fork。
3. 保持公开 Python 包不依赖 Rust 或 Codex 源码。
4. 创建范围明确的 Pull Request，清楚描述问题。

文档改动应同时更新英文和简体中文页面。网站构建会拒绝缺少对应语言页面的提交。
