Efferva 采用 Apache-2.0 许可证，以开放方式开发。

## 开始贡献

1. 阅读仓库工程约束。
2. 将产品行为保留在 Efferva 中，并保持 Codex fork 精简。
3. 为行为变化增加测试。
4. 运行 Python、Rust 与相关集成检查。
5. 创建范围明确的 Pull Request，清楚描述问题和验证结果。

文档改动应同时更新英文和简体中文页面。网站构建会拒绝缺少对应语言页面的提交。
