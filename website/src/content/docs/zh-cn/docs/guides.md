面向实际任务的指南正在为首次公开预览编写。

计划包括：

- 将 Efferva 接入已有认证体系的 FastAPI 产品
- 把产品角色映射为 Efferva Capability
- 通过 PostgreSQL 运行多个应用实例
- 断线后恢复 AG-UI 与 SSE 事件流
- 增加并验证自定义沙盒 Provider
- 打包和部署平台 Wheel

:::tip[关注进展]
关注 [Efferva 仓库](https://github.com/tinypoint/Efferva)，即可看到新指南的更新。
:::
